# Licenses and notices

SillyMaker's project-owned engine code is MIT licensed. The Engine Lab, starter
template, and first-party examples expose two stable `rel="license"` links in
their baseline HTML:

- [SillyMaker MIT license](https://github.com/jasl/silly-maker/blob/main/LICENSES/MIT.txt)
- [Maintained third-party notices for the hosted Player baseline](https://github.com/jasl/silly-maker/blob/main/THIRD_PARTY_NOTICES.md)

The third-party notice page records a verified minimum observed in the current
first-party Vite bundles and includes the applicable copyright and license text.
It is deliberately not an exhaustive inventory for every possible Story:
application dependencies, optional features, and future bundle changes can add
other material.

If you distribute a customized Player, inspect the bundle you actually ship and
make every applicable notice available. Hosted builds may use a durable public
link; installed or offline packages should carry the required texts locally. A
technical Artifact manifest is optional and is not a legal inventory.
