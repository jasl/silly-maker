**最后一次试音**是 SillyMaker 维护中的旗舰 Reference Product：一部从 tracked
starter 起步、以真实产品而不是纵向切片完成评审的原创紧凑型 Visual Novel。

[在本站构建中游玩](../../../play/vn-last-sound-check/)

## 产品分母

- 110 个唯一可见文本条目，任一路线 82 个；
- 两名有姓名的角色、两个作者场景、一个实质选择、两条不同路线和两个结局；
- 完整的中英文文本包，以及最终视觉与音频素材；
- 引擎维护的 VN Player、Save/recovery、History、Back/Forward、Auto、
  skip-read、响应式输入与无障碍行为；
- 人类和 Agent 接手共用同一套 Inspector/CAS 作者路径。

Browser Player 作为本站可发布产物的一部分位于 `/play/vn-last-sound-check/`。
Deno Desktop 仍是支持的开发目标；本页不声称已经另行发布原生版本。

## 证据边界

独立 product/engine review 已通过，Starter 不需要追加修改。代表性真实
current-low-end qualification 没有执行：由于没有相应设备，所有者取消了它作为本产品完成
门槛。这不构成低端设备支持证据。
