示例是可独立运行的作品，而不是孤立的 API snippet。目标标准是容易理解、可发布的
产品，但每个当前条目都明确自己的真实职责，不借用其他示例的完成度。

- **最后一次试音**——维护中的旗舰 Reference Product：一部原创、完整的双路线 VN，
  覆盖默认 Player、Save/recovery、音频、i18n、响应式 UI 与 Inspector 辅助创作。
  [查看说明](./vn-last-sound-check/)或[在本站构建中游玩](../../play/vn-last-sound-check/)。
- **SillyOS**——从 Creator Home 进入 Program Workspace 的浏览器本地 Agent 产品。
  唯一内置的 Agent Creator 支持确定性预览和已配置的 Provider 路线，使用产品固定版本
  的 Pi、typed Worker RPC、本地 Program 数据库与 OPFS mutable checkpoint。隔离的
  Workspace Sandbox 和 Network Broker 需要
  [独立部署](https://silly-os.jasl9187.workers.dev/)。
