This page owns the human-oriented map from product intent to source files.

## Stable top-level roles

- `engine/packages/` — reusable engine packages.
- `template/` — the copyable starting application.
- `examples/` — complete products used to evaluate the engine.
- `website/` — this public site and its bilingual Markdown sources.
