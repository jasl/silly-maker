## Admission 裁决（车道开启时固化）

- **无新动词。** Host / skip / headless 只报 `TimeTickV1`。对 hold
  的 input resolve 继续 `interaction.kind_mismatch`。不复活
  `hold_abort`。
- **`when` 是 branch 词汇的加法。** hold 块可选
  `when?: readonly { when: Compare; next: string }[]`——每条臂必须带
  谓词，声明序第一条命中获胜，没有隐式 else（else = 继续持有或到期
  走块上 `next`）。比较字段与该 Story 的 branch 上下文同一入院。
- **评测时机。** 围栏 tick 的 commit 顺序：折 remaining → 本 hold
  的 tick/`frames` 穿越 → `settleMonitorsV1` → 评 `when`。命中则结
  束 occurrence、走该臂 `next`、丢弃剩余毫秒（不为丢弃余量再计穿
  越）。未围栏 tick 不折 hold、不评 hold `when`。
- **入场也评。** 打开 hold 的那次 commit 按当时已提交状态内联评
  `when`（提案 q2：不发明 0ms `TimeTick`）。入场已真 → 立刻改道。
- **skip。** 折清先走完全部剩余穿越，再评 `when`；折清后为真走改
  道，不走到期 `next`。
- **不进 pending / Save。** `when` 与改道 `next` 是节点声明，与到
  期 `next` 同纪律。
- **hold 中热区（提案 q1）显式 defer。** V1 只覆盖时间/监视器/tick
  效果写入的权威状态。条中途点身体是输入轴，缺第二条 admission，
  不把 regionId 塞进 hold resolution。第一活路径是警戒抓包或深夜房
  条中途觉醒/厌恶。

## 里程碑

- M0 合同与 runner：kit hold 块收 `when` 臂；打开 hold 与围栏 tick
  按 admission 评测；合同测试锁穿越改道、入场改道、skip 改道、批切
  不变、中持有 Save/load。template kit 与实验仓 kit 同一字段。
- M1 Engine Lab 消费者：`cal-hold`（或一条新 drill）用 tick / 监视
  器把谓词写真，断言同一 commit 改道；Flow 图 hold 节点标出改道
  边。
- M2 实验仓活路径 + 文档收口：接警戒抓包**或**深夜房条中途觉醒/
  厌恶（先到的那条）；features / story-authoring / production-floor
  / AGENTS 更新。另一条真中止与 hold 中热区不在本切片。

## 验收

- `{500,500,500}` ≡ `{1500}` 下改道时刻与终态 / digest 相同；
- 入场已真 → 零流逝改道，不留下 hold pending；
- skip 折清后谓词为真 → 改道；
- 中持有 Save/load 后续走载入状态，不重演墙钟；
- 对 hold 的 input resolve 仍 `kind_mismatch`；CommandLog 无新
  resolution kind；
- Lab 一条路径 + 实验仓一条真中止路径。

## Defer

- hold 中热区（输入轴；见提案 q1）。
- 第二条真中止路径（M2 只接一条）。
- 监视器路由叙事（仍禁）。
- `when` 臂的 Studio 可视化编辑（Flow 只投影边）。

## Stop conditions

沿用 production-floor §9 与提案「停」节。本计划内特别注意：

- 新增中止动词或 Host 选臂 → 停；
- 监视器 / 热区获得路由权 → 停；
- `when` 抄进 pending / Save，或谓词读墙钟 / 指针 → 停；
- 推荐用法变成逐谓词一条命令 → 停。
